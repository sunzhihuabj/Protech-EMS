## 二、环境适配决策（本地机 ≠ 生产环境）

| 生产（规格） | 本机现实 | 适配方案（记 DECISIONS.md） |
|---|---|---|
| JDK 11 | 仅 JDK 25 | `maven.compiler.release=11`：产物仍是 Java 11 字节码；验证在 JDK 25 上运行 |
| GreatDB / MySQL 8.0.33 | MySQL 9.6（已运行） | DDL 只用 MySQL 8.0 标准语法；测试用 H2(MySQL 模式) 跑 Flyway，真实 MySQL 9.6 做冒烟导入验证 |
| Redis 5+ | memurai 6379（已运行，Redis 协议兼容） | 直接使用；代码层留 KeyValStore 接口 + 内存实现兜底（CI 无 Redis） |
| RabbitMQ 3.12 | 未安装 | S0 不阻塞：消息组件 `@ConditionalOnProperty`，默认关闭；生产开启 |
| Docker Compose | 无 Docker | 提供 docker-compose.yml 供生产；本地用 `run-local.md` 手工起 MySQL/Redis |
| 微信小程序/OnlyOffice | 无法真实对接 | 集成层全部适配器模式 + MOCK 模式（规格本就要求 mock 可跑通） |

## 四、S0 内部施工序（本阶段）

S0-1 仓库与 Maven 骨架 → S0-2 Flyway T-SYS 14 表+T-AI 2 表+枚举字典种子 → S0-3 认证（JWT+锁定+首登强改） → S0-4 RBAC → S0-5 数据范围拦截器 → S0-6 审计切面 → S0-7 编码引擎（18 类） → S0-8 字典管理 → S0-9 文件上传/下载/水印 → S0-10 导入框架 → S0-11 导出脱敏 → S0-12 通知中心 → S0-13 AI 网关（mock+降级+调用日志） → S0-14 前端主布局（按权限渲染菜单） → S0-15 种子数据（14 部门/18 角色/9 板/审批模板/字典） → S0-16 部署与备份脚本 → S0-17 12 套预编译主题与 Web 端切换。

## 五、全流程通用工程规范

- 代码注释与 commit message 中文；类/字段英文；Service 方法顶部注释标 FR 编号。
- 统一响应包 `ApiResponse<T>`（code/message/data/traceId）；硬卡点统一 422 + `data.blockCode`。
- 所有业务表：`deleted TINYINT`、审计四字段、乐观锁 `version`（单据主表）、无外键约束。
- 金额 `BigDecimal`+`DECIMAL(18,2)`；枚举 `VARCHAR(24)` 英文大写 code；JSON 字段不建索引。
- 编码取号只走 `CodeSequenceService`；跨模块只经 `api` 包接口，禁止注入对方 Mapper。
- 每阶段产出 `docs/SPRINT-Sx.md` 并勾稽需求册条目（防偏离验证）。
