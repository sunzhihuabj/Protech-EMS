# 11 · 模块 H：成本、看板与经营分析（D12）

> 本模块回答两个问题：**这个项目到底赚没赚**（成本与三口径毛利），以及 **每天卡在哪**（九板看板与红灯过堂）。
> 规则编号 `FR-COST-nn` / `FR-KB-nn`。

---

## 1. 模块目标

| 目标 | 定义 | 反面（现状） |
|---|---|---|
| 成本口径唯一 | 七项成本、三种毛利口径固定，各系统不得各算一套 | 财务、商务、工程各算一套，开会吵架 |
| 预算可控 | 预算→目标→实际三算对比，超支预警 | 年底才知道亏了 |
| 进度成本联动 | EVM 的 SPI/CPI 同屏 | 只知道延期，不知道延期花了多少钱 |
| 指标自动取数 | 板头指标从业务表聚合，不靠人填 | 日报 16.7 天才交 |
| 红灯必须闭环 | 超 3 天自动升级，链主无权压卡 | 红灯长期挂着没人管 |

## 2. 成本模型

### 2.1 成本七项（唯一口径，写进代码常量）

| 成本项 | 来源 | 归集维度 | 说明 |
|---|---|---|---|
| 材料成本 | 出库事务 × 成本单价（`inv_transaction.amount`） | 项目 | 发货出库 + 现场领料 |
| 人工成本 | 报工工时 × 费率（`cost_labor_rate`）；非生产人员按月估工时 | 项目 | 一期用标准费率，不做实际工资分摊 |
| 外协成本 | 采购订单（CG 合同）实际到货金额 | 项目（按合同关联） | 安装外包、运输等 |
| 现场费用 | 报销审批通过金额 | 项目 | 交通/住宿/餐补/外包 |
| 质保成本 | 质保期内工单成本 | 项目 | 物料 + 人工 + 差旅 |
| 呆滞损失 | 呆滞处置损失金额 | 项目（能归因时）/ 公司池 | 无法归因的进公司池，不摊项目 |
| 其他直接费 | 手工录入（检测费/认证费等） | 项目 | 需附说明 |

### 2.2 三种毛利口径（必须同时给出）

| 口径 | 公式 | 用途 | 陷阱 |
|---|---|---|---|
| **合同毛利** | （合同金额 − 已确认成本）÷ 合同金额 | 项目全周期视角 | 项目进行到一半时"成本"是不完整的，容易高估毛利 |
| **阶段毛利** | （已开票金额 − 已发生成本）÷ 已开票金额 | 月度经营视角 | 开票节奏影响大（先开票后干活的月份毛利虚高） |
| **现金毛利** | （已回款金额 − 已付现成本）÷ 已回款金额 | 现金流视角 | 未付现的成本（应付未付）不体现 |

> **为什么必须三个都给**：源文件里"毛利率"这个词在财务、商务、工程三个部门指的不是同一件事。只给一个数，等于制造吵架。

### 2.3 功能需求

| 编号 | 需求 | 规则 |
|---|---|---|
| FR-COST-01 | 成本归集 | 每日 02:00 定时按七项汇总到 `cost_snapshot`；支持手动重算 |
| FR-COST-02 | 成本来源可追 | 每个成本项可下钻到来源单据（采购单/报工记录/费用单/出库单） |
| FR-COST-03 | 三口径毛利 | 项目详情同时展示三种毛利 + 口径说明（可点开看公式） |
| FR-COST-04 | 成本构成 | 七项占比图；点击下钻 |
| FR-COST-05 | 预算编制 | 项目立项后编制；按成本科目（可细分到物料/阶段）；支持多版本 |
| FR-COST-06 | 预算审批 | 项目经理编 → 财务审 → 分管批 |
| FR-COST-07 | 三算对比 | 预算 / 目标成本 / 实际成本 三列对比 + 偏差率 + 偏差额 |
| FR-COST-08 | 超支预警 | 偏差率 >±10% 通知项目经理与财务；>20% 红灯卡 |
| FR-COST-09 | 预算调整 | 超预算支出需走调整审批，记录原因与审批意见 |
| FR-COST-10 | EVM | 计算 PV（计划值）/EV（挣值）/AC（实际成本）→ SPI/CPI；按里程碑或月度 |
| FR-COST-11 | 待发生成本 | 已下单未入库采购额 + 未完工工单预估 = 待发生；与已发生合计为"预计总成本" |
| FR-COST-12 | 项目损益表 | 收入（已开票/已回款）− 成本七项 = 毛利；可导出 |
| FR-COST-13 | 产品线毛利 | 按产品线聚合（同口径），标出负毛利产品线 |
| FR-COST-14 | 客户毛利 | 按客户/集团聚合；识别"高量低利"客户 |
| FR-COST-15 | 费用对比 | 现场费用按项目/区域/人天对比；异常高值（>均值 2 倍）提示 |
| FR-COST-16 | 工时费率配置 | 按角色或工作中心配置；变更只影响后续快照，不回溯 |
| FR-COST-17 | 成本快照 | 每日一版；可对比任意两天；用于回溯"毛利是怎么变的" |
| FR-COST-18 | 呆滞损失不摊项目 | 除非能明确归因到 ECN；否则进公司池（防项目毛利失真） |

### 2.4 业务规则

| 编号 | 规则 |
|---|---|
| BR-COST-01 | 三口径必须同时展示，禁止只给一个"毛利"数字 |
| BR-COST-02 | 成本只认系统内单据；线下发生的必须补单才计入（补单标 `is_backfill=1`） |
| BR-COST-03 | 费率变更不回溯历史快照 |

## 3. 看板体系

### 3.1 九板结构（B 的 1+4+4）

| 层级 | 看板 | 主责 | 参与 | 节奏 | 板头指标 |
|---|---|---|---|---|---|
| 总板 | ① 公司经营总看板 | 总经理部 | 全部链主 | 周一 30 分钟 | 新签合同额/在手订单/回款率/逾期应收/毛利率/全公司红灯总数 |
| 日板 | ② 订单交付 | 商务部 | 销售/计划/采购/生产/仓储/工程/财务 | 每日 15—30 分钟 | 订单准时交付率/在手齐套率/开票及时率/回款率/逾期应收 |
| 日板 | ③ 供应链 | 计划部 | 采购/仓储 | 每日 | 采购准交率/到货及时率/账实相符率/缺料预警数 |
| 日板 | ④ 生产制造 | 生产部 | 工艺/质量/计划 | 每日 | 工单准交率/开工齐套率/一次检验合格率/工时达成率 |
| 日板 | ⑤ 工程交付 | 工程技术部（+系统集成组） | 质量/商务 | 每日 | 项目准时开工率/方案交底及时率/验收一次通过率/现场问题闭环时长/本周现场支持费用 |
| 周板 | ⑥ 研发 | 技术中心研发组 | 工艺/生产 | 每周 | 里程碑达成率/BOM 发布及时率/样机验证周期/图纸变更闭环率 |
| 周板 | ⑦ 市场销售 | 销售团队 | 市场部 | 每周 | 新增商机数/报价转化率/投标中标率/新签合同额 |
| 周板 | ⑧ 财务 | 财务部 | 商务 | 每周 | 应收账龄结构/逾期率/回款计划达成率/费用预算执行率 |
| 周板 | ⑨ 企管 | 企管部 | 各部门接口人 | 每周 | 招聘到岗率/培训完成率/制度落地项/安全隐患整改闭环率 |

**三个设计取舍**（写进产品说明，防止被"纠正"）：
1. **不按部门设板**——14 个部门里 7 个不足 5 人（市场部 2 人），按部门设板会出现"2 人板无米之炊 + 27 人板看不过来"，且 14×30 分钟 = 每天 7 小时组织成本；
2. **技术中心一拆二**——研发组 10 人（周频）与系统集成组 17 人（日频）节奏与业务性质不同；集成组并入⑤板辅控泳道上游，因为"方案延误的唯一后果就是现场停工"，两边卡点是同一个；
3. **不设总经理部部门板**——3 人，它的管理界面就是①总板。

### 3.2 四区一栏

| 区域 | 放什么 | 更新 | 早会用法 |
|---|---|---|---|
| 指标区（板头） | 3—5 个硬指标：目标/实际/状态灯 | 自动取数，每日刷新 | 开场 3 分钟只报红灯数 |
| 进行区 | 在办且未受阻的卡片 | 责任人实时拖动 | **不看、不念** |
| 红灯区 | 受阻/超期/待决策的卡片 | 出现即挂，解决才摘 | 会议 80% 时间逐卡过堂 |
| 闭环区 | 近 7 天已关闭的卡片（含结果） | 关闭即归档 | 每周盘点闭环率 |

### 3.3 卡片五要素（缺一不许上板）

| 要素 | 规则 | 校验 |
|---|---|---|
| 事项 | 可交付可验收；**禁止**"跟进/推进/协调/加强/督促/关注/落实/配合/了解" | 命中模糊词 → 标 VAGUE + 上板警告 |
| 责任人 | 唯一且具体到人（`owner_id`），不写部门名 | 必填且必须是用户 |
| 承诺完成日 | 责任人自报；经理可上调、**不可下调** | 改小需填"提前理由"并经链主确认 |
| 当前状态 | 未开始/进行中/受阻/已完成 | 枚举 |
| 卡点说明 | 红灯必填：卡在谁手上、缺什么、需要谁拍板 + 下一步动作 | BLOCKED 时两项必填，否则拒绝保存 |

**正确**：`P-1224 龙源湖南合同审核盖章并寄出`
**错误**：`跟进龙源湖南合同`（判 VAGUE）
**红灯示例**：事项 `远景 P-0896 自消组件备货`｜卡点 `缺 2 项外购件，采购已下单未到货，卡在供应商`｜下一步 `采购 10/12 到货后当日发运`

## 5. 异常处理

| 场景 | 行为 |
|---|---|
| 指标 SQL 执行失败 | 该指标显示"数据异常"灰色，不影响其他指标；记错误日志告警 R03 |
| 指标无数据 | 显示"—"而非 0（0 与无数据含义不同） |
| 两人同时拖同一卡 | 乐观锁，后提交提示"已被 XX 修改"，刷新对比 |
| 责任人离职 | 卡片自动转部门负责人并推送；转交留痕 |
| 会议中断（刷新/断网） | 会议状态存服务端可恢复；已过堂记录不丢 |
| 卡片挂错板 | 允许"移动到其他板"（填理由）；原板闭环区显示"已移出" |
| 升级后问题已解决但未改状态 | 提示"该卡已升级 X 天，是否已解决？"；连续 7 天未处理推送给分管副总 |
| 成本快照与实时值不一致 | 显示快照时间戳，提示"数据截至 X 时"；可手动重算 |

## 6. 验收要点

1. 某项目合同 100 万、已开票 60 万、成本 45 万 → 阶段毛利 25%，同时显示合同毛利与现金毛利。
2. 成本七项合计 = 总成本（误差 ≤1 分）。
3. 预算 100 万、实际 115 万 → 偏差率 15% → 通知项目经理与财务；>20% 进红灯。
4. EVM：PV=80 万、EV=70 万、AC=75 万 → SPI=0.875、CPI=0.933。
5. 建卡写"跟进龙源湖南合同" → 标 VAGUE 要求改写。
6. 红灯不填卡点说明 → 拒绝保存。
7. 红灯挂起 4 天 → 自动上总板，链主界面无"取消升级"。
8. 跨部门挂卡 48h 无响应 → 自动升级并推送 4 类人。
9. 会议模式：3 分钟到点变色；每卡 2 分钟计时；三问未填可跳过但记"未闭环过堂"；结束生成纪要。
10. 连续 3 天未开会议 → 链主收提醒。
11. 板头指标可下钻，明细合计 = 指标值。
12. R11 查看财务看板金额 → 为 null。

**声明：本方案为产品设计参考，具体实施请结合公司合规与法务要求确认。**
