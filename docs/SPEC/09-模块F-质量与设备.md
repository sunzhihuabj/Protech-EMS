# 09 · 模块 F：质量与设备（D08 + D09）

> 质量模块的直接动因来自 BOM 审计的一条结论：**工艺文件覆盖率与产品风险等级严重不匹配**——自动消防是安全关键件，工艺覆盖仅 4.7%。质量体系不是"多填几张表"，而是让安全关键件的每个环节都有记录、可追溯、能改进。
> 规则编号 `FR-QMS-nn` / `FR-EAM-nn` / `FR-SCA-nn`。

---

## 1. 质量管理（QMS）

### 1.1 三个检验关口

```
IQC 来料检验      采购到货 → 生成检验任务 → 按 AQL 抽样 → 判定（合格/让步/退货/筛选）
IPQC 过程检验     工序报工(需检) → 首件/巡检 → SPC 采集 → 判定
OQC 成品检验      完工 → 出厂检验 → 合格方可入库
```

| 关口 | 触发点 | 抽样依据 | 不合格处置 |
|---|---|---|---|
| IQC | 采购到货（`pur_receipt`） | 按物料类别维护的 AQL 方案 | 退货 / 让步接收（技术+质量会签）/ 筛选（生成筛选工单） |
| IPQC | 工序 `need_inspection=1` 完工 | 首件必检 + 巡检频次 | 返工 / 停线 / 转 MRB |
| OQC | 生产订单完工 | 产品标准（全检或抽样） | 返工 / 报废 / 特采（需 R02） |

### 1.4 业务规则

| 编号 | 规则 |
|---|---|
| BR-QMS-01 | AI 检测结果不自动判定，必须由质检员做出最终结论（`qms_inspection.result` 只能人写） |
| BR-QMS-02 | 让步接收必须技术 + 质量双会签，且记录在 MRB |
| BR-QMS-03 | 超期未校准的量具不得用于任何检验记录（下拉不可选） |
| BR-QMS-04 | OQC 不合格的生产订单不得入库 |
| BR-QMS-05 | 8D 关闭必须有 D6 效果验证证据，且验证期 ≥30 天 |
| BR-QMS-06 | SPC 超限点必须有人"确认并处置"（填原因/措施），否则该特性持续标红 |

## 3. SCADA 试点（C-12 裁决：只做 1—2 台设备）

### 3.1 范围与边界

| 项 | 一期范围 | 不做 |
|---|---|---|
| 设备 | 选 1—2 台关键设备（建议：焊接机器人 或 测试台） | 全厂联网 |
| 采集 | 运行/停机/待机状态、产量计数、关键参数（温度/压力） | 远程控制、参数下发 |
| 协议 | OPC-UA 或 Modbus TCP → 边缘网关 → 本系统 | 直连 PLC |
| 频率 | ≥1Hz 采集，≤500ms 延迟 | 高频振动/声发射 |
| 用途 | OEE 自动计算、实时状态看板 | 预测性维护 |

### 3.2 功能需求

| 编号 | 需求 | 规则 |
|---|---|---|
| FR-SCA-01 | 数据采集 | 通过边缘网关采集设备状态与计数；断网本地缓存 ≥24h，恢复后补传 |
| FR-SCA-02 | OEE 计算 | `OEE = 可用率 × 性能率 × 良品率`；可用率=（计划时间−停机）/计划时间；性能率=（实际产量×理论节拍）/运行时间；良品率=良品/总产 |
| FR-SCA-03 | 实时监控 | 设备状态图、运行参数实时显示、异常报警 |
| FR-SCA-04 | 历史趋势 | 关键参数历史曲线（保留 2 年，按月聚合后删明细） |
| FR-SCA-05 | 报警联动 | 设备异常 → 报警 → 自动生成 EAM 维修工单 + Andon 提示 |
| FR-SCA-06 | 试点评估 | 输出"试点 ROI 报告"：OEE 提升、停机减少、数据完整性，作为是否扩面的依据 |

### 3.3 边界说明

> SCADA 投入大（传感器 + PLC 改造 + 网络 + 网关），**一期只做试点，不做全厂**。若试点 ROI 为负或数据质量不达标，直接停止，不做二期。这是明确的范围控制，不是能力不足。

## 4. 异常处理

| 场景 | 行为 |
|---|---|
| 检验任务无人接 | 超过 4 小时未接 → 提醒质量主管；8 小时 → 进红灯卡 |
| AI 检测置信度 <60% | 标灰"建议人工全检"，不显示结论，避免误导 |
| SPC 数据不足 25 组 | 不计算控制限，提示"样本不足，暂用规格限" |
| FMEA 检索无相似项 | 返回空并提示"未找到相似历史记录，请新建" |
| 量具校准超期仍在用 | 该量具在检验单下拉中不可选；已用超期量具的检验记录标"测量系统存疑" |
| 设备故障但无维修人 | 工单自动转设备责任部门负责人 |
| SCADA 数据中断 >10 分钟 | 该时段 OEE 标"数据缺失"，不按 0 计算（避免失真） |

## 5. 验收要点

1. 采购到货 500 件，AQL 2.5 → 自动算样本量 50、Ac=3/Re=4。
2. 检验合格 → 到货单可入库；不合格 → 生成退货单且不可入库。
3. AI 检测返回"不合格/缺陷位置/置信度 0.87"→ 质检员判定仍可改，改后 `human_corrected=1`。
4. 首件未检验 → 批量生产开工按钮不可用。
5. SPC 30 组数据 → 控制图有 UCL/LCL，2 个超限点标红；Cpk 计算正确。
6. Cpk=1.12 → 自动生成过程改进任务并通知质量负责人。
7. FMEA 检索"机舱消防管路接头" → 返回 3 条相似记录（RPN 降序）。
8. 8D 未填 D6 验证证据 → 关闭被拒。
9. 量具校准到期 → 检验单下拉不可选；超期使用记录标"存疑"。
10. 备件领用 → INV 生成出库事务。
11. 设备 3 次故障、总运行 720h → MTBF=240h；总修复 6h → MTTR=2h。
12. SCADA 试点设备 OEE 计算与手工核算一致（误差 ≤2%）。
