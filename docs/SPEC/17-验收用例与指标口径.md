# 第一部分：指标口径（唯一事实源）

## 1. 通用规则

| 规则 | 内容 |
|---|---|
| 时点 | 全部 `Asia/Shanghai`；"本月"= 自然月 1 日 00:00 至月末 23:59 |
| 金额 | `DECIMAL(18,2)` 元；展示可选万元（保留 2 位）；除税口径需明示 |
| 订单归属 | 按 `sign_date` 归期，不按录入日 |
| 排除项 | 内部关联交易（`is_internal=1`）单列，不计入客户口径；作废/取消单据排除 |
| 除零 | 分母为 0 返回 `null` 展示"—"（**不显示 0%**） |
| 手工指标 | 仅"制度落地项""培训完成率"允许手工，标"手工"角标；每板最多 1 个 |
| 延迟 | 日指标每日 06:00 刷新（显示 T-1）；周指标周一 06:00；红灯数每 2 小时 |
