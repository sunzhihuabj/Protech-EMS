## M10-3 数据字段（T-ENG 16）

`eng_crew`（班组）、`eng_worker`（人员/证件/保险到期/身份证密文）、`eng_project_ext`（项目工程扩展：风场/台数/点位）、`eng_install_plan`（分项/首台/计划实际）、`eng_unit`（机组：`unit_no` UK/产品线/安装日/状态）、`eng_acceptance`（类型/结论/签字件）、`eng_daily_log`（日期/内容/照片/`ai_check_result`/离线标记）、`eng_quality_check`、`eng_rectification`（来源/期限/复核）、`eng_progress`、`eng_cost_budget`/`eng_cost_actual`、`eng_safety_check`、`eng_material_issue`（领用/退库/废料）、`eng_dispatch`（`dispatch_no` UK/项目/风场/班组/物料明细）、`eng_after_sales`（工单/项目/机组/处理）。

校验：派工台数=拆挂台数；销项数量 ≤ 发货数量；整改未闭环禁验收；费用必挂 `dispatch_id`。

## M10-4 状态与流转

```
派工：TO_DISPATCH → DISPATCHED → DOING → TO_ACCEPT → DONE → CLOSED（旁支 SUSPENDED）
安装：PLANNED → INSTALLING → TO_DEBUG → DEBUGGING → TO_ACCEPT → ACCEPTED
整改：PENDING → DOING → TO_REVIEW → PASSED → CLOSED（不通过回 DOING）
机组：TO_INSTALL → INSTALLING → TO_DEBUG → ACCEPTED → WARRANTY（12/60 月）→ EXPIRED
售后：TO_DISPATCH → DISPATCHED → DOING → TO_ACCEPT → CLOSED（可挂起/转派）
```

## M18-4 状态与流转

```
公告：PENDING → PARSED / MANUAL / INCOMPLETE → ACTIVE → SUPERSEDED / CONVERTED / CLOSED / EXCLUDED

抓取批次：CREATED → RUNNING → SYNCED / FAILED（batch_no 幂等）
```

## M18-7 异常与边界

| 场景 | 行为 |
|---|---|
| 站点改版（解析率 <60% 连续 3 天） | 停源 + 告警 R18 |
| 反爬 403/验证码 | 退避 + 告警；**禁止绕过**；持续则转人工导入 |
| AI-015 不可用 | 原文入 MANUAL，09:00 提醒，不丢数据（UC-BID-06） |
| 同公告双源 | 合并 1 条，仅推 1 次（UC-BID-02） |
| 延期公告 | 关联原公告，只推新截止日（UC-BID-03） |
| 打分 42 | 不推送，归档可查（UC-BID-05） |
| robots 禁抓 | 置 DISABLED + 人工导入（UC-BID-09） |
