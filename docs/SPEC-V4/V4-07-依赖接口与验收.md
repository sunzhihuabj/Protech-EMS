### 3.1 接口通用约定（摘要，全文见 V4-01 §7）

- 路径四分区；统一响应包；`201` 不用、`202` 仅异步创建；分页默认 20/最大 200；

- 错误码：1001/2001/2002/2003/3001/4001/5001/6001/9001；`blockCode` 四命名空间。

## 四、数据校验规则

### 4.1 通用 10 条（所有写接口）

| # | 规则 | 失败返回 |
|---|---|---|
| 1 | 必填校验（字段级 `@Valid`） | 1001 + `errors[]` |
| 2 | 类型/长度/枚举合法性（枚举必须属于 E-xx） | 1001 |
| 3 | 金额：字符串→BigDecimal，≤2 位小数，≥0（红冲单除外） | 1001 |
| 4 | 日期：不早于业务约束（如交期 ≥ 签订日） | 1001 |
| 5 | 引用存在性：所有 `*_id` 必须存在且未停用 | 3001/1001 |
| 6 | 唯一性：业务编码、幂等键 | 4001/1001 |
| 7 | 状态机：仅允许白名单跃迁 | 5001 + 当前状态 |
| 8 | 数据范围：非授权数据不可见/不可写 | 403 |
| 9 | 硬卡点：BR-01—09 | 422 + blockCode |
| 10 | 并发：`version` 不匹配 | 409 + currentVersion |

### 4.2 跨模块一致性校验

| 校验 | 规则 | 触发点 |
|---|---|---|
| 项目编码贯穿 | 派工/工单/发货/报销必挂 `project_id` | BR-03，四类单据提交 |
| 数量闭环 | 销项 ≤ 发货；领料 ≤ 入库；到货累计 ≤ PO×(1+超收) | M10/M05/M04 |
| 金额闭环 | 报价→合同→开票→收款 逐级可对 | M01 |
| 主数据引用 | 业务表只存 `*_id`，名称从主数据取（禁冗余名） | 全部 |
| 成本闭环 | 七项合计 = 总成本（误差 ≤1 分） | M12 |
| 指标一致性 | 看板/导出/接口三处同值 | UC-DAT-01 |

### 4.3 边界条件矩阵（8 类）

| 类别 | 典型场景 | 期望行为 |
|---|---|---|
| 空 | 列表无数据/未配字典/项目无成员 | 空状态 + 主行动按钮 |
| 超限 | 金额溢出/行数 >5000/附件 >500MB/导入 >5 万行/分页 >200 | 前端预校验 + 服务端硬限 + 明确上限文案 |
| 重复 | 重复提交/24h 重复扫码/同名建档/并发保存 | 幂等返回首次/二次确认/查重拦截/409 |
| 时间 | 跨月签合同/节假日顺延/跨年编号/时区 | 归属按 `sign_date`；节假日表可配；按自然年重置 |
| 金额 | 0/负数/精度/红冲/税率变更 | 拒 0 负（红冲除外）；BigDecimal；红冲用负向单 |
| 权限 | 越权/范围外/离职账号/第三方过期/跨主体 | 403/立即失效/双人确认 |
| 状态 | 非法跃迁/回跳/撤销/并发 | 白名单/反向动作单/409 |
| 外部 | T+ 挂/AI 超时/OnlyOffice 失败/断网/Storage 满 | 各自降级不阻塞；队列重试；界面明示"待同步" |

## 五、指标口径（唯一事实源）

时区 `Asia/Shanghai`；"本月"=自然月；金额 `DECIMAL(18,2)` 元；订单归属按 `sign_date`；内部关联交易 `is_internal=1` 单列；分母 0 显示"—"不显示 0%；手工指标每板 ≤1 个并加"手工"角标；日指标 06:00 刷新（T-1），红灯数每 2 小时。
