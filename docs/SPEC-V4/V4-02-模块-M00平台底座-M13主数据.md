## M00-4 状态与流转

```
用户： PENDING（新建）→ ACTIVE ⇄ DISABLED（停用即踢会话）→ 离职（保留审计）
导入批次：CREATED → DRY_RUN → IMPORTING → SUCCESS / PARTIAL / FAILED
附件版本：V1 → V2 → …（旧版只读，可回滚为新版本）
```

## M00-5 权限规则

- 服务端判权（`@RequirePermission`）+ 数据范围拦截器双拦截；前端 `v-permission` 仅控显隐。
- R03 无业务数据写权（防越权）；敏感字段明文可见需 R01/R15 + 单独审计。
- Agent 复用同一权限体系（M19）。

## M00-6 异常与边界

| 场景 | 行为 |
|---|---|
| 取号并发 | `sys_code_sequence` 行锁 + `version`；冲突重试 ≤3 次；仍失败 409 |
| 重复账号/角色名 | 1001 字段级错误，指出冲突字段 |
| 上传伪装文件（.exe 改 .jpg） | 真实 MIME 校验拒绝（UC-SYS-12） |
| 下载路径穿越 `../../etc/passwd` | 规范化后拒绝，记审计（UC-SYS-11） |
| 字典删除被引用 | 拒绝，提示引用数与替代项 |
| 导入中途失败 | 整批回滚，报告保留错误行 |
| 通知通道故障 | 重试 3 次后落"未送达"并提供站内兜底 |

## M13-4 状态与流转

```
客户/项目/物料/供应商：DRAFT → ACTIVE ⇄ DISABLED（停用需给替代/理由）→ MERGED（合并后子记录）
项目档案：pending（待补全，owner_pending/farm_pending=1）→ complete（关键 12 项齐）
清洗批次：CANDIDATE → REVIEWING → APPLIED → ROLLED_BACK
档案：REGISTERED → BORROWED → RETURNED → DESTROYED（审批后）/ TRANSFERRED
```
