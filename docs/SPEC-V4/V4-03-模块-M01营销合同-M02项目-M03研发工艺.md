## M01-4 状态与流转

```
商机：TRACKING → QUOTING（有报价）→ WON →（转合同）/ LOST →（重激活）TRACKING
报价：DRAFT → SUBMITTED → WON（→转合同）/ LOST / EXPIRED（过有效期自动）
合同：DRAFT → REVIEWING → APPROVED → SIGNED → FILED（建档完成）→ PERFORMING → ACCEPTED → WARRANTY → CLOSED
      旁支：REJECTED（回 DRAFT）/ CHANGING（-BCn 审批中）/ FROZEN（超期未建档，仅冻结开票）
收款：PLANNED → RECEIVED（待确认）→ CONFIRMED →（逾期）OVERDUE
```

**关键约束**：合同进入 FILED 前不可 PERFORMING；FROZEN 不影响合同本身状态，只阻断开票（BR-02）。

## M01-6 异常与边界

| 场景 | 行为 |
|---|---|
| 评审未选项目（BR-01） | 422 + `BR-01` + "去建档"链接（UC-CT-01） |
| 六要素未勾全 | 拒绝并高亮（UC-CT-02） |

| 报价低于成本下限 | 红字告警 + 需 R05 确认，**不阻断**（防拍价但保留灵活性） |
| 同客户同项目重复报价 | 提示撞单，可继续但需填理由（FR-CRM-15） |
| 变更金额差 >5% | 强制重走评审 |
| 删除 BC2 而 BC1 存在 | 拒绝；只能作废保留编号（UC-CT-16） |
| 金额精度 | 全部 BigDecimal；前端传字符串；四舍五入仅展示层 |
