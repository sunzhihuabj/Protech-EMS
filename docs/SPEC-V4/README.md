## 三、AI Agent 阅读路径

```
1. V4-00（决策与术语，10 分钟）
2. V4-01 §5 数据规范 / §6 接口规范 / §7 非功能（实现任何模块都要遵守；注：章节号见 V4-01 正文）
3. 目标模块所在卷的对应 M## 章（固定 8 段：定位/功能/字段/状态/权限/异常/接口/验收）
4. V4-07 §4 校验规则 + §8 待确认清单（有 Q 项按建议默认值执行，记 docs/ASSUMPTIONS.md）
5. 自测：模块 §8 验收表 + V4-07 §6 用例编号
禁止：跳读其他模块卷；跨模块交互只通过 V4-07 §3 接口清单与 §2 依赖矩阵
```

## 四、模块—功能—规则编号

```
M##        模块（M00—M19，与原 D00—D19 一一对应；字母编号 A—J 已废弃）
FR-XX-nn   功能（沿用原编号；新增按原前缀续号）
R          规则（该功能下的校验点，在功能表"规则"列）
BR-0x      全系统硬卡点（仅 9 处）
UC / NFR / Q / E   用例 / 非功能 / 待确认 / 枚举
```

## 五、与 V3.3 的主要差异

1. 结构：23 册 → 8 卷（一个卷 = 一条可独立交付的链路）；
2. 命名：模块 A—J + D## 双轨 → **M## 单轨**；
3. 补齐：报价单（`crm_quotation` + 4 FR + 4 UC）、商机来源字段、平台底座 24 条 FR 编号化；
4. 修正：工期 30—34 周单口径、库房 99%/98% 分期目标、钉钉为统一入口、接口四分区、blockCode 命名空间；
5. 治理：字段只写在模块卷（总册只登记），消除"唯一事实源 vs 外置域"张力。
