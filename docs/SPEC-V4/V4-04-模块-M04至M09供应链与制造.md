# M04 供应链（原 D04）

**M04-1 定位**：供应商五阶准入 → 采购需求四来源 → 合并下单 → 到货/退货 → 物流 → 价格库。上游 M03（BOM 齐套）、M13（物料/供应商）；下游 M05（到货入库）、M12（成本）。不做：供应商在线报价（二期）；招投标代理。范围 40 FR（FR-SCM-01—40）+ 9 表。

**M04-2 功能**

| 功能号 | 功能 | 规则 | 优先级 |
|---|---|---|---|
| FR-SCM-01 | 供应商准入五阶 | 注册→资料→现场→样品→合格；未合格不可下单 | Must |
| FR-SCM-02 | 资质到期管控 | 过期 → SUSPENDED，下单拒绝（UC-SCM-02） | Must |
| FR-SCM-03 | 供应商分级五档 | 战略/核心/一般/备选/淘汰；影响分配比例 | Should |
| FR-SCM-04 | 供应商评价 | 周期评分（准交/质量/价格/服务） | Should |
| FR-SCM-05 | 采购需求四来源 | ①BOM 齐套缺料（自动）②安全库存 ③项目专用 ④备货（总经理批） | Must |
| FR-SCM-06 | 需求合并 | 同供应商合并 1 单，行保留项目 | Must |
| FR-SCM-07 | 采购建议 | 按价格库/交期/分级推荐（AI-005 可选） | Should |
| FR-SCM-08 | 采购订单 | `PO-` 编号；价格权限脱敏 | Must |
| FR-SCM-09 | PO 下发 | 通知库房/质检/生产，**不含价格**（UC-SCM-05） | Must |
| FR-SCM-10 | 分批到货 | 多次到货；累计不超订单 | Must |
| FR-SCM-11 | 超收控制 | >5% 需审批（UC-SCM-06） | Must |
| FR-SCM-12 | 退货 | 质检不合格 → 退货单；PO 部分退货 | Must |
| FR-SCM-13 | 价格库 | 三次不同价留痕 + 趋势 | Must |
| FR-SCM-14 | 物流录入 | 手工/快递100（M15）；时间线 | Should |
| FR-SCM-15 | 到货提醒 | 预计到货前 1 天提醒 | Must |
| FR-SCM-16 | 准交率统计 | 按期到货行 ÷ 应到货行 | Must |
| FR-SCM-17 | 单一来源预警 | 仅 1 家合格供应商的物料占比 | Should |
| FR-SCM-18—40 | 询价/框架协议/请购审批/预算校验/合同关联/发票匹配/T+ 对账/黑名单/导入导出/审计 | 通用：唯一编号、金额服务端算、幂等 | Should |

**M04-3 字段（T-SCM 9）**：`scm_supplier_onboarding`（阶段/资料）、`scm_supplier_qualification`（证照/到期）、`scm_supplier_evaluation`、`scm_price_history`、`scm_purchase_requirement`（来源/项目/需求日/数量/状态）、`scm_purchase_order`（`po_no` UK/供应商/金额/状态）、`scm_purchase_order_item`（行/数量/单价/到货量）、`scm_purchase_return`、`scm_logistics`（运单/时间线）。校验：金额=Σ行；到货累计 ≤ 订单×(1+超收)。

**M04-4 状态**：供应商 `REGISTERED → QUALIFYING → QUALIFIED ⇄ SUSPENDED / BLACKLIST`；需求 `DRAFT → SUBMITTED → MERGED/APPROVED → ORDERED → CLOSED`；PO `DRAFT → ISSUED → PARTIAL_RECEIVED → RECEIVED → CLOSED`（旁支 `RETURNED/CANCELLED`）。

**M04-5 权限**：`scm:supplier:*` R09；`scm:po:*` R09（禁审自己单）；价格 `scm:price:view` 限 R09/R10/R15/R01；R11 查 PO 无价格（BR-06）。

**M04-6 异常**：未准入/资质过期下单 → 拒绝；超收 8% → 审批；到货不合格 → 退货 + 不可入库；PO 已下发改价 → 禁止（作废重开）。

**M04-7 接口**：`POST /scm/requirement`（四来源）｜`POST /scm/po`｜`POST /scm/po/{id}/receive`（超收）｜`GET /scm/price/history`（脱敏）｜`POST /scm/return`。

**M04-8 验收**：准入/过期（UC-SCM-01/02）｜齐套一键请购（03）｜合并保留项目（04）｜超收审批（06）｜R11 无价格（08）。

# M05 库存与库房（原 D05）

**M05-1 定位**：T+ 为账面权威、本地事务流水 + 扫码即记账 + 每日对账；治"账实不符"。上游 M04（到货）、M06（领料）；下游 M10（发货）、M12（成本）。**目标 99%，首年验收 98%（D-06）**。范围 26 FR + 11 表。

**M05-2 功能**

| 功能号 | 功能 | 规则 | 优先级 |

| FR-INV-02 | 两司隔离 | 物料按 `legal_entity`；跨主体扫码拒绝（UC-INV-05） | Must |
| FR-INV-03 | 库存事务 | 只增不改不删；幂等键 | Must |
| FR-INV-04 | T+ 同步 | PENDING_SYNC → SYNCED / EXCEPTION；退避 3 次 | Must |
| FR-INV-05 | 缓存查询 | TTL 5 分钟；显示"截至时间" | Must |
| FR-INV-06 | 扫码入库 | 到货单 → 扫码 → IQC 合格 → 入库 | Must |
| FR-INV-07 | 扫码出库 | 发货/领料驱动；超可用量拒绝（UC-INV-13） | Must |
| FR-INV-08 | 离线队列 | 断网 ≥5 条，同步去重（UC-INV-04） | Must |
| FR-INV-09 | 条码/二维码 | 标签打印；批次/序列号 | Must |
| FR-INV-10 | ABC 循环盘点 | A 月/B 季/C 半年；盲盘 | Must |

| FR-INV-13 | 同根因升级 | 同因当月第 3 次 → 专项整改（UC-INV-10） | Should |
| FR-INV-14 | 呆滞台账 | 90/180 天；处置矩阵 | Must |

| FR-INV-18—26 | 期初建账/调拨/借出归还/报废/库容/效期/批次追溯/盘点计划/审计 | 通用 | Should |

**M05-3 字段（T-INV 11）**：`inv_transaction`（type/物料/数量/货位/来源单/`idempotency_key` UK/状态/`t_voucher_no`）、`inv_stock_cache`（物料/货位/现存量/可用量/`synced_at`）、`inv_batch`、`inv_count`/`_line`、`inv_diff`（差异/归因/审批级）、`inv_slow_moving`、`inv_disposal`、`inv_replenish`/`_line`、`inv_reconcile`。**禁建"权威库存数量表"**（C-04）。

**M05-4 状态**：事务 `PENDING_SYNC → SYNCED / EXCEPTION`；盘点 `CREATED → COUNTING → REVIEWING → DIFF_HANDLING → ADJUSTED → CLOSED`；补货 `APPLIED → APPROVED → ISSUED → SIGNED_BACK → CLOSED / LOCKED`。

**M05-5 权限**：`inv:txn:*` R11；调账按金额分级；价格不可见（BR-06）；跨主体调拨双人确认。

**M05-6 异常**：T+ 挂 → EXCEPTION 不阻塞（UC-INV-03）；重复提交 → 幂等（UC-INV-02）；未归因 → 拒绝；25h 未签 → 锁定。

**M05-7 接口**：`POST /inv/transaction`（Idempotency-Key）｜`GET /inv/stock`（缓存+截至）｜`POST /inv/count/{id}/submit`｜`POST /inv/diff/{id}/adjust`（分级）｜`GET /inv/reconcile/daily`。

**M05-8 验收**：扫码全链（UC-INV-01）｜幂等（02）｜T+ 挂（03）｜离线（04）｜三级调账（06—08）｜对账（14）｜账实 98%/99%。

**M06-6 异常**：前道未完 → 禁用；错料 → 锁定+Andon；超计划 10% → 必填原因；补录标 `is_backfill`（补报率 ≤10%）。
