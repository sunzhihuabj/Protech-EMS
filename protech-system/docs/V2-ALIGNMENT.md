## 四、环境适配决策（本机约束 → 不违背 09/11 册交付）

| 约束 | 决策 |
|---|---|
| 本机无 Docker / 无 PostgreSQL | `prisma/schema.prisma` 以 **postgresql** 为唯一事实源（交付物）；另生成 `schema.sqlite.prisma` 镜像（sync 脚本产出）供本机开发/测试 `db push`。约束：不用 Prisma `Json`/`enum` 标量——一律 `String` 列 + `shared-types` 常量校验（枚举存 code 的 05 册规范反而在应用层更硬）；JSON 用 TEXT 列+应用层序列化（吸取 Java 项目 H2/MySQL JSON 教训） |
| 本机有 Memurai :6379 | BullMQ 直连（Redis 协议兼容），缓存/队列按 11 册设计不变 |
| 本机无 MinIO | `StorageService` 接口两驱动：`disk`（dev/test）/`s3`（prod MinIO）；compose 文件按 11 册交付 |
| Node 24（规格基线 Node 20） | 向后兼容，TS 编译 target Node20；若 NestJS 10 对 Node24 有 peer 冲突则升 NestJS 11 并在此登记 |
| pnpm 缺失 | npm workspaces（Monorepo 结构不变） |
